# ReExtractor v1.3.4

本版本恢复与旧版内置更新器的兼容性，同时保留版本号可见的发布方式。

## 修复

- 修复旧版“检查更新”能够发现新版本、但下载后因找不到固定名称 `ReExtractor.Gui.exe` 而无法完成安装的问题。
- Windows x64 ZIP 额外附带同版本的 `ReExtractor.Gui.exe` 兼容副本，仅供旧更新器完成这一次接力升级；正常启动文件仍是 `ReExtractor-v1.3.4.exe`。

## 版本标识

- ZIP、解压目录、主 EXE 和窗口标题均带 `v1.3.4`。
- 完成兼容升级后，后续更新继续使用带版本号的 EXE，并保留旧文件供回退。
