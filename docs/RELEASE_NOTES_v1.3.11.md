# ReExtractor v1.3.11

## 修复

- 修复《怪物猎人：崛起 / 曙光》NPC 多分件播放动画时的骨架错乱。
- 动画主骨架按蒙皮骨数选择，避免脸部或头发分件因补充辅助骨后总数更多而取代身体骨架。
- 撤回 v1.3.8 / v1.3.9 测试包中错误的 NPC 旋转转换，恢复原始 MOT 旋转。
- 容忍模型中同名辅助骨，修复 `npc615_00` 的 `wst_chain_end` 重复骨名导致动画加载异常。

## 验证

- 覆盖 MHR list 中全部 23 套同时具有身体、脸部和头发的 NPC。
- 累计检查 394 条动作、1,976 个组合姿势采样和 1,704,051 个旋转关键帧，无分件脱离、非有限顶点或旋转数据被改写。
- 定点检查 `npc002_00_00` 的 `mot_9` 第 227/480 帧：坐姿与单手抬起姿态正常。
- 重现并验证 `npc615_00` 重复辅助骨名修复。
