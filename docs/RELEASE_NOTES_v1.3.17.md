# v1.3.17

预览模型导出现在会等待 FBX 和 MDF 关联贴图全部处理完，再恢复导出按钮并显示完成，避免 FBX 已生成时误以为整个导出已经结束。

- 关联贴图导出先创建 `textures` 文件夹，显示保存位置和处理进度。
- 在 `textures` 中保留逐张导出日志，包括成功路径、失败原因和最终数量；没有可导出贴图时也留下说明。
- MDF 引用的贴图找不到时，预览导出日志及批量导出结果会明确提示。

验证：通过实际预览 FBX 导出处理流程，静御前普通身体模型生成 FBX 和 21 张 PNG，其中包含 5 张 NRRO 法线相关贴图；按钮在贴图处理期间保持禁用。空引用、全部导出失败和缺失 MDF 贴图引用的回归检查通过。

已知限制：该模型另有 1 张三维噪声纹理因不支持 Depth > 1 而导出失败，日志会记录原因。法线及辅助贴图以 PNG 保存，不自动连接 FBX 材质。本地完整等待后未复现反馈中的“完全没有法线”，本版不将其宣称为已确认解决的问题。
