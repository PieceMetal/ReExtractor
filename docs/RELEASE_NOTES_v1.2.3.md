# ReExtractor v1.2.3

本版本修复模型导出后的贴图关联与导出状态问题。

## 主要更新

- 导出 FBX 时自动重新读取已加载模型分件及其 MDF，无需事先点击“加载贴图”。
- 将可解码的基础色贴图写入 FBX 同名 `.fbm` 目录，并保留 FBX 材质的图像引用。
- MDF 引用的其他 TEX 通道继续批量导出到 `output/textures`，方便后续制作材质。
- FBX 主文件生成后立即结束主进度并恢复导出按钮；关联贴图后处理不会再锁住模型导出界面。
- 关联贴图后处理失败时保留已经生成的 FBX，并在日志和状态栏中明确提示。

## 下载与环境

- 发布包：`ReExtractor-v1.2.3-win-x64.zip`
- 支持 Windows 10 / 11 x64。
- 压缩包内仅包含 `ReExtractor.Gui.exe`。
- FBX 导出需要单独安装 Blender。
