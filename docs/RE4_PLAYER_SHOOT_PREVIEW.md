# RE4 普通枪械射击组合与资源关联

部分500/501/502轨道只有射击增量，直接作为完整动画播放会接近T姿态。
它们的基础姿态与矿车射击、上半身起止/换弹的层序不同，需要单独读取游戏配置。

`Re4PlayerShootAnimationResolver`读取已加载PAK中Leon的角色Prefab：
主层0播放`ch0Common`的HOLD树，附加层5播放`ch0CommonUpperBodyAdd`的SHOOT树。
主层为完整姿态，附加层为局部旋转/位移增量，两层权重均为1、遮罩均为0，未使用世界旋转。
动作树通过公共库Bank2引用；树的叶动作通过武器库Bank2000定位，不跨库猜动作编号。

HOLD树的三个输入是160持枪循环、165左转、167右转；SHOOT树的三个变体是500/501/502。
界面明确选择固定输入和射击变体，先读取完整基础姿态，再叠加射击增量。
主动作按原速播放并控制检查时长；短射击轨道保持末帧，叠加关闭及0%使用相同基础姿态和时长。
静态160输入虽然只有零时刻关键点，仍保留MOT声明的432帧/60fps检查窗口；不会生成零时长组合。
这是动作检查方式。游戏通过WheelBlendRate/WheelSpeed控制转向、速度并随机选择射击变体；
本实现不求值这些变量、状态切换、其他活动层、手部覆盖、持枪定位或IK。

## 资源关联

`Re4AnimationResourceCatalog`只解析完整资源引用与显式BaseMotListPath链。
仅当本列表对应槽为空且标志为255哨兵时沿继承链查找，不把动作树/链接或镜像轨道当成空槽。
已找到的源路径、源索引和继承链保存在ResolvedAnimationMotion中；预览以本列表原槽索引选择，
加载时读取实际源轨道。继承基础动作会在名称和说明中标识来源。
缺失、重复、循环或不支持的配置保留诊断，不按名字、编号邻近或其他角色资源猜配对。

本次适配范围为武器库中实际内嵌这组三条普通射击变体的22个cha0列表，共66条射击变体。
每个列表提供三个持枪输入与三个射击变体，共198个固定组合。
其中11个列表通过继承链补齐33条基础输入；wp4411H的基础姿态沿wp4401H继承到wp4400H。
仅有继承射击轨道的其他列表、510 aftershoot及1130等特殊shoot未据此确认。
wp4410H的500/501/502原始通道全部为零位移和单位旋转；它们没有骨骼后坐力增量，
组合开关不会产生姿态变化。界面会明确说明“零增量”，不能把加载成功当作射击表现通过。
轨道的附加用途单独保存，即使基础姿态缺失，也不会把已确认的附加轨道当成完整动作。

可选武器库和各个动作列表分别隔离读取异常。一个库的引用全部验证成功后才登记其
资源上下文；损坏库、缺失引用或损坏列表会记录具体路径，不再中断其他武器的普通
射击解析。公共玩家层、HOLD/SHOOT 动作树及骨骼遮罩的校验仍然保留。

“当前动画”导出当前组合，作为普通动画播放；“全部动画”及批量导出保持本列表原始内嵌轨道，
不自动烘焙射击组合，也不扩展继承内容。离线17组配对快照不添加未经当前资源核实的160组合。

## 验证命令

```text
dotnet run --project tools/Re4ShootPreviewTests -c Release -- catalog <results> <game-directory> <list-file>
dotnet run --project tools/Re4ShootPreviewTests -c Release -- preview <results> <game-directory> <list-file>
dotnet run --project tools/Re4ShootIsolationTests -c Release -- <game-directory> <list-file> <results>
```

针对反馈列表可设置环境变量 `REEXTRACTOR_AUDIT_LISTS` 为
`cha0_wp4000h_ex.motlist.663;cha0_wp4100h.motlist.663`。若请求的列表未解析出组合，
测试会失败，避免空集合通过。隔离测试覆盖损坏库、缺失引用、有效/无效混合引用、
损坏列表以及登记上下文的原子性；故障样本在结果目录生成，不修改游戏 PAK。
这些故障注入用于验证程序缺陷，不代表已经确认反馈者实际安装中的触发资源。
将 `REEXTRACTOR_AUDIT_FAULT_FOLDER` 设为隔离测试输出下的 `malformed-bank` 目录，
可重跑 preview：它会为 GUI 装入带故障样本的新资源集合，验证诊断仍存在且正常
射击仍有 198 个组合，目标列表的用途筛选、配对选择和蒙皮导出仍通过。

preview模式使用真实身体、头部、头发三个模型，检查配置和继承保护、界面组合选择、
每帧关键值、覆盖持枪时窗和短射击段的原生蒙皮姿态、叠加开关/0%一致性和当前组合GLB读回。
同时回归已有上半身和矿车组合。数值、自动界面和导出检查不代表全部组合已人工看过，
也不代替游戏或UE运行验收。

RE4后续资源管理界面可复用这些关联记录，按角色、武器及动作组合显示来源、依赖和缺失原因。
本次仅建立解析与现有预览所需的关联模块，尚未提供独立资源管理页面。
