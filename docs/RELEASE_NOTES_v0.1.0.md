# ReExtractor v0.1.0

ReExtractor 的首个公开预览版本，提供从 RE Engine PAK 加载、资源检索、模型与动画预览，到 UE 可用 FBX 导出的完整桌面工作流。

## 本版重点

- 支持单个、多选和拖入 PAK，也可扫描游戏目录自动加载基础包与 Patch PAK。
- 提供本地及在线 list 管理、校验、更新和模糊资源搜索。
- 支持 TEX 贴图、Mesh 模型、骨骼、模型组与 MotionList 动画预览。
- 支持角色分件合并，合并模型可同步播放动画并作为一个模型导出。
- 模型 FBX 与动画 FBX 分区导出，动画支持单个/全部、30 FPS/60 FPS。
- 提供透视镜头、六方向视图、全部取景、选中取景和世界坐标轴。
- 设置、日志、list、临时文件和默认输出采用 EXE 旁便携目录。
- 中文界面、底部状态区、可调整高度的输出日志和加载/导出进度提示。

## 游戏兼容性

- 《鬼武者：剑之道》DEMO：已完成真实 PAK、模型、贴图、骨骼、动画与 FBX 流程验证。
- 《街头霸王 6》：PAK 解包和 list 路径还原具备支持基础；模型材质、流式 Mesh 与部分动画仍为实验性。
- 其他 RE Engine 游戏：需要对应 list，并可能需要适配新的资源格式版本。

## 使用前准备

- 下载并解压 Windows x64 便携包。
- FBX 转换需要单独安装 Blender，并在“设置”中选择 blender.exe。
- 请仅处理你合法拥有的游戏资源。

## 已知限制

- RE Engine 的复杂眼睛、皮肤和透明材质无法通过普通 FBX 材质完整还原。
- 不同游戏的 MDF、流式 Mesh 和外链动画格式可能需要单独适配。
- 首个版本属于预览版，建议保留原始 PAK 与导出结果备份。
