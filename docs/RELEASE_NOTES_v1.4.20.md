# ReExtractor v1.4.20

- 修复 GitHub issue #3：移除单次 Blender FBX 转换固定 60 分钟的强制终止限制，较大的动画列表可以继续运行至 Blender 实际完成。
- 保留现有进度、退出码、脚本完成标记和完整转换日志检查。不会主动删除此前导出的 FBX。

下载 `ReExtractor-v1.4.20-win-x64.zip`，解压运行 `ReExtractor-v1.4.20.exe`。FBX 导出仍需要已安装 Blender 并配置路径。

验证：Release 构建及模拟 Blender 的成功、缺少完成标记、非零退出、双管道大量输出、进度/日志和已有文件保留回归通过。尚未用真实游戏资源实测超过 60 分钟的转换，因此不声称已完成该长时实测。

已知限制：本版没有新增取消按钮或卡死检测。单个大动作期间进度可能较久不更新；Blender 若真正卡死，会持续等待，必要时需手动结束对应的导出 Blender 进程（不要结束其他 Blender 会话）。关闭主窗口不保证结束子进程。
