# ReExtractor v1.3.13

## 修复与新增

- 修复《鬼武者》正式版材质读取失败、模型加载贴图后仍为灰色的问题，兼容该游戏的 MDF 51 布局和特殊材质文件名。
- 修复路径列表未收录 streaming 资源时，高分辨率贴图被 PAK 索引过滤的问题；存在流式贴图时优先读取，没有时保留原尺寸贴图。
- 修复分件模型和动画预览正常、导出却被绑定差异拦截的问题。导出保留各分件的独立绑定，通过预览使用的主骨架同步动画。
- 动画轨道按骨骼名称匹配，避免错误套用其他骨骼的同序号轨道；模型导出保留最多 8 个蒙皮权重。
- 动画 FBX 附带绑定参考网格，保持模型与动画的参考骨架一致。导入为动画时，可关闭“导入网格 / Import Mesh”。更新程序后会同步更新内置导出脚本。
- 资源目录树和搜索结果支持右键“批量导出选中模型 FBX”，每个模型独立输出，保留资源目录以避免同名覆盖；单项失败后继续导出其余模型。
- 右键“添加选中模型到合并器”和合并器的“添加选中”均支持多选、去重。
- “加载预设”默认进入当前游戏的预设目录，新增“打开预设目录”，悬停预设数量提示可查看完整路径。
- 打开列表管理器时先显示缓存，再获取 Ekey/REE.PAK.Tool 的 Projects 在线目录；保留 Eigeen 来源，显示“新增”和“可更新”。网络异常时保留缓存和内置目录，不会自动下载列表或切换游戏。

## 使用说明

- 右侧“导出预览模型 FBX”导出预览内容，合并预览输出为一个 FBX。
- 右键“批量导出选中模型 FBX”按左侧多选逐个导出至 `output/models`。
- 预设位于程序旁的 `output/presets`，按游戏分类保存。

## 验证范围

- 正式版角色 `ch001_00` 的 `00 / 01 / 02 / 10 / 20` 五个分件及 `plw_grapple` 中的 `mot_860`：模型、动画成功导出为 FBX，并由 Blender 回读。
- 五个动画采样点与预览计算对比，FBX 最大位置误差约 0.014 毫米；模型静止回读最大位置误差约 0.030 毫米。模型与动画共有骨骼的绑定矩阵和父子关系一致。
- 正式版 18 张贴图样本中，17 张读取到更高分辨率资源，1 张无流式资源的 8×8 贴图保留原尺寸；测试版四个实际角色分件贴图回归通过。
- 6 项流式 PAK 回归、3 项 MDF 布局回归通过；多选、混合资源筛选、去重及单项失败继续批量导出通过。
- 在线列表实测发现 93 项，`OWOTS_STM_Release.list` 下载及校验通过，`O2_SD_STM_Release.list` 保持独立。

上述结果针对已列出的样本与 Blender 回读，不代表所有游戏、角色、动作或 UE 导入均已验收。
