# ReExtractor v1.4.21

- 批量／全部导出时，文件名包含源动作名，保留列表名、索引和动作 ID。没有源名时沿用旧命名，文件名不允许的字符会替换为下划线。
- 本次调整的是文件名，不更改 FBX 内部动画栈或烘焙设置。之前已导出的文件不会自动重命名。

下载 `ReExtractor-v1.4.21-win-x64.zip`，解压后运行 `ReExtractor-v1.4.21.exe`。导出 FBX 需要已安装并配置 Blender。

验证：覆盖继承动作、重名、非法字符、空名和长名称的合成测试；《鬼武者：剑之道》148 个动作导出 GLB 并回读检查动画通道，抽查 3 个用 Blender 转成 FBX，文件名均保留源动作名。
