# v1.3.20

- 预览模型导出采用“名称_LOD档位.fbx”，不再附加“合并几个模型”。当前模型组合与加载的预设完全匹配时使用预设名，否则使用首个源模型资源名。文件名中的非法字符会替换为下划线。
- Blender 转换完整输出保存在 `ReExtractor-tools/logs/fbx-*.log`，包含程序路径、脚本、输入输出路径和退出码；失败提示会给出日志位置。
- 设置 Blender Python 异常退出码，避免脚本异常仍返回代码 0；进程正常退出但缺少成功标记时，明确提示“未收到脚本完成标记”。

验证：本机 `ch001_50_00` 的 LOD0 实际生成 FBX 和 73 张 PNG。未复现反馈中的转换失败，本版增强诊断，不宣称已修复其未知原因。
