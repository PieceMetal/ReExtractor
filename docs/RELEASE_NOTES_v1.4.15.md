# ReExtractor v1.4.15

改善继承动作的来源提示，方便辨认动作列表与源动作的关系。

## 更新内容

- 动作继承自基础列表时，在动画选择框下方显示实际来源列表；悬停提示可查看完整路径。多级继承显示实际包含该动作的列表，本列表内嵌动作不显示继承提示。
- 例如《鬼武者：剑之道》的 em112 攻击列表引用 em106 基础列表，源动作名称可能以 Em106 或 Em301 开头，界面现在会显示其来源。

## 验证与边界

- 使用本机资源核对 em112 攻击列表的 67 个动作来源，并检查编号 59、240、242 的读取；验证多级继承、本地覆盖和界面提示切换、清除。
- 反馈日志中另有两次“没有可读取的动作”，未记录对应列表路径，原因尚未确认，本版不宣称解决该问题。
- 未进行实际窗口视觉验收或反馈者环境复测。
