# ReExtractor v1.4.11

本版修复新版《龙之信条 2》PAK 加载、蒙皮与材质导出问题。

- 支持标志位 `0x68` 的 PAK 扩展分块表，修复加载前报错；分块资源按声明长度输出，避免尾块多余数据。
- 识别 `.mesh.260421070`（内部版本 `251205828`）的八字节骨骼索引，修复动画播放和 FBX 导出后的网格拉伸。
- 补充 `.tex.251211553` 路径解析，优先匹配 streaming 贴图；补齐已验证 DD2 表面材质的法线、金属度和粗糙度通道。
- FBX 转换时将打包的金属度／粗糙度拆成独立贴图连接，并核对贴图文件是否实际写入。
- 命令行材质预览导出预先建立 PAK 索引，避免每个候选路径重复读取目录表。

## 验证范围

- 实际 DD2 主包 318,956 个条目、15 个空补丁包；80 个资源读取抽样。
- ch20_000 模型待机及攻击动作重新导出 FBX，并检查多个帧的灰模截图。
- ch20_000 身体、眼睛、口腔三个材质，FBX 重新导入后颜色、法线、粗糙度和金属度连接及外部贴图文件验证。
- 原有材质匹配测试及新增 DD2 贴图后缀回归。

## 限制

以上为明确样本验证，不代表所有 DD2 模型、动作和游戏运行时着色器均已覆盖。关联的 20 张 TEX 可全部提取，19 张可转 PNG；其中一张体积特效用的 3D 纹理保留 TEX，当前不能转 PNG。动态腐化、积雪等效果不属于本次静态 PBR 材质验证范围。

Windows x64 发布包：`ReExtractor-v1.4.11-win-x64.zip`，仅包含 `ReExtractor-v1.4.11.exe`。
