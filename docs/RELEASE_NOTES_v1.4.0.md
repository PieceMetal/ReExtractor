# v1.4.0

本次更新围绕工具内反馈、公共评论和配套反馈后台，资源加载、模型预览及导出逻辑沿用上一版本。

- 新增反馈侧栏，支持粘贴或选择图片、附带运行日志，草稿保存在本机。
- 公共评论显示 R友昵称和日期，支持分页，并与后台同步隐藏及清档结果。
- 优化附件预览、移除按钮、空状态和窄窗口布局；反馈入口支持拖动，侧栏增加开合动画。
- 配套后台支持多选发送修复、页面内二次确认、当前会话接收、进度回写和中止请求，保留反馈原文及 AI 回复。
- 管理员可隐藏、恢复评论、屏蔽或解除屏蔽发送设备，永久删除放在归档内。

修复任务转交依赖管理员本机接收器与 Codex 运行；用户发送评论不依赖管理员在线。中止为通知会话停止后续工作，不强制结束外部程序。

验证范围：反馈界面、草稿及附件自动测试；真实公共评论同步；后台发送到当前会话、进度回写和中止回执联调。本次未重新执行导出功能回归。

Windows x64 压缩包仅包含 `ReExtractor-v1.4.0.exe`。本地预设、设置和日志不包含在发布包中。
