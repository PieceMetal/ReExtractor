# ReExtractor v1.4.12

本版修复《怪物猎人：崛起 / 曙光》部分玩家装备加载动画后的身体分件错位。

## 修复

- 部分装备省略了 `Cog → Waist_00 → Spine_00` 等父级，直接把后续骨骼挂到 `Root`。原先加载动画只补进缺失骨骼，没有将已有装备骨骼重新连接到完整动画父级链，可能造成头盔被拉高、身体与装备分离。
- 现在根据 Rise 动画的父级关系补全确实省略的祖先链，保留原始蒙皮索引和逆绑定矩阵；同时更新新增辅助骨的绑定，使预览与导出使用一致的姿态。
- 此处理限定于 Rise 的 MOT 格式和可确认的省略祖先路径，不改写其他游戏的动画骨架。

## 使用

更新后重新加载角色装备和对应动画。已经导出的异常模型或动画需要重新导出；配套模型和动画请选择相同的导出轴向。

## 验证范围

- 男女 `pl004` 的身体、手臂、头盔、腿和腰部五个分件；双刀 `plw_DualBlades_100_001_Loop` 第 0、50、92、100、150、200 帧与完整玩家骨架比对。
- 单件与组合预览、不同加载顺序、每套连续切换 8 个双刀动作，原始蒙皮逆绑定矩阵保持不变。
- 男女组合动画 GLB 经 Blender 读回，与实际预览姿态的蒙皮网格比对通过。
- 代表男性装备按 Unity 轴向分别导出模型 FBX 和动画 FBX，再导入 Blender 配套播放；骨骼名称及父级一致、模型为一个网格、动画不含网格，代表帧蒙皮比对通过。
- `npc501_00` 原有 NPC 检查：20 个动作、100 个姿态采样通过。修复版软件已通过后台实际加载并暂停在反馈对应的第 92 帧。

以上为明确样本的验证，不代表全部 Rise 装备、动作、物理约束或游戏运行时效果均已覆盖。本次尚未进行 Unity 编辑器实际导入验收。
