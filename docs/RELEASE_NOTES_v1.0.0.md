# ReExtractor v1.0.0

ReExtractor 是面向 Windows 的 RE Engine 资源解包、预览与导出工具。本版本统一整理了 PAK/list 管理、资源预览、模型合并、动画播放和 FBX 导出流程。

## 主要功能

- 支持打开、拖入单个或多个 PAK，也可选择游戏目录自动扫描 PAK。
- 支持本地及在线路径 list 管理、搜索、切换和游戏目录匹配。
- 不预置特定游戏的路径 list，首次启动保持空白并由用户按需下载或导入。
- 支持 TEX 预览及 PNG / DDS 导出。
- 支持 Mesh、骨架、材质、贴图和 MotionList 动画预览。
- 模型默认快速加载几何，可按需单独加载贴图。
- 支持模型分件叠加、同骨架模型合并和合并动画播放。
- 支持导出当前预览模型，以及当前动画或整个 MotionList 的独立动画 FBX。
- 首次启动提供环境检测，可配置 Blender 和默认导出位置。
- 程序生成的 list、设置、日志、缓存和导出文件统一放在 EXE 同级目录。

## 视口与交互

- 视口采用 X 轴向右、Y 轴向前、Z 轴向上的坐标约定。
- 左下角世界坐标轴会随镜头同步，方向与视口世界保持一致。
- 调整默认透视角度、观察距离、全部取景居中和鼠标环绕方向。
- 未加载模型时仍可操作视口。
- 修复资源列表部分区域无法双击、右键菜单命中范围不完整的问题。

## FBX 导出修复

- 修复 Blender 5.x 下访问旧版 `Action.fcurves` 接口造成的动画导出报错。
- 统一模型和动画 FBX 的 Y 前向、Z 向上设置及骨骼主轴。
- 修复 UE 导入后的模型朝向、骨架轴向、缩放和蒙皮对应问题。
- 修复根骨骼位移被重复转换，导致动画在 UE 中沿负 Z 向下移动的问题。
- 动画按有效帧范围烘焙并逐个输出，不包含模型网格。
- 导出过程显示当前项与总项数。

## 下载与环境

- 发布包：`ReExtractor-v1.0.0-win-x64.zip`
- 压缩包内只有 `ReExtractor.Gui.exe`，运行数据由程序自行生成。
- 支持 Windows 10 / 11 x64。
- FBX 导出需要用户单独安装 Blender，并在工具设置中选择 `blender.exe`。

## 兼容性

- 《鬼武者：剑之道》DEMO：已验证 PAK、贴图、模型、骨架、动画预览与 FBX 导出流程。
- 《街头霸王 6》：已验证 PAK、list、模型基础材质与贴图读取；部分资源版本仍需继续适配。
- 其他 RE Engine 游戏的支持程度取决于 PAK、Mesh、TEX、MDF 和 MotionList 格式版本。
