# ReExtractor v1.3.15

修复《鬼武者：剑之道》静御前模型找不到贴图，以及批量模型导出遗漏法线、遮罩等关联贴图的问题。

## 修复内容

- 材质查找支持 `_c`、`_c_event_00`、`_d_event_00` 命名，保留原有材质候选优先级。
- 静御前头部显示使用四宫格表情图集的左上中性表情，修复重复五官。原始关联 PNG 保留完整图集。
- 批量导出与预览导出共用 MDF 关联贴图导出逻辑，输出至 `textures` 文件夹。法线和辅助贴图作为 PNG 导出，不自动连接 FBX 材质。
- 导出提示明确辅助贴图的保存位置。

## 验证与范围

- 本地正式版全部 4 个 PAK（包含补丁、DLC）只读测试，命名资源 103079 项。
- 静御前六个分件修复前均未找到贴图，修复后均恢复加载。去重后 74 张关联资源中 72 张成功导出 PNG，包含基本色、法线及遮罩。
- 身体和服饰主要基本色、法线为 2048×2048；部分头发和腰带为 1024×2048。头部原始图集为 2048×2048，显示使用的单个象限为 1024×1024，没有缩放降采样。
- 身体 FBX 已经 Blender 重新导入验证，模型、骨架和外部图像引用存在；头部修复完成导出渲染检查。
- PAK streaming 六项回归、MDF 三项布局回归通过。

仍不支持两张三维特效纹理（`19_noise_100_MSK4`、`tex_capcom_vectorfield_0003_MSK4`）转 PNG，失败项保留提示。未在用户机器、UE 或 3ds Max 中完成验收，不能视为所有资源全量通过。

## 安装

下载 `ReExtractor-v1.3.15-win-x64.zip`，解压后运行唯一的 `ReExtractor-v1.3.15.exe`。也可通过旧版本的“检查更新”安装。
