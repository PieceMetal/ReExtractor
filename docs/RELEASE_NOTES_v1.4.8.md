# ReExtractor v1.4.8

修复单文件 EXE 在自动下载 RSZ 元数据前发生异常，导致 SCN 预览提示 `RSZ json file setting is not configured` 的问题。

下载器现在直接读取程序集版本元数据，不再依赖单文件打包后为空的程序集文件路径。HTTP User-Agent 使用固定的合法产品名称，避免启动文件名影响请求头。

首次使用仍需联网下载对应游戏的元数据；已有有效缓存可以继续使用，无需手动配置 RSZ 路径。

## 验证范围

- v1.4.7 EXE 在独立空缓存中复现：读取文件版本时抛出空路径异常，HTTP 请求启动次数为 0，最终报 RSZ 未配置。
- 修复后的单文件 EXE 使用独立空缓存，成功从真实资源服务器下载 RE4 资源索引、RSZ 模板、补丁及引用信息，并完成 RSZ 解析器初始化。
- 普通运行及单文件发布回归通过：HTTP 异步/同步下载、空缓存填充及离线缓存重新加载。
- 此次验证针对元数据下载与解析器初始化，不代表所有游戏或任意 SCN 的完整预览验收；反馈者未提供具体游戏和资源路径。

本次不包含其他动画、模型、材质或导出功能改动。
