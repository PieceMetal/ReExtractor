# ReExtractor v1.4.10

修复《祇：女神之路》的模型显示、主角动画变形和动画 FBX 导出问题。基于 v1.4.9，保留已有 RE4 和 RSZ 修复。

## 修复内容

- Mesh 主 LOD 与阴影 LOD 共用对象时，保留主顶点缓冲区，避免被辅助缓冲区覆盖后得到空模型；补充 TEX 231106777 贴图查找。
- 读取模型配套 JCNS 26 标量约束，将腰胯、膝盖和腿脚的辅助骨驱动烘焙到动画。未支持的约束类型不会猜测执行。
- 针对主角 ch0100_damage 的 MOT 799 旧受击 0–4 号动作，在资源身份和轨道特征同时匹配时转换小腿、脚踝和脚趾坐标基准。保留动作编号、时间、位移与缩放，预览和导出共用处理；不替换成其他动作。
- 不再向此受击列表追加未参与动画的旧辅助骨，保持主角模型和动画的 234 骨架一致。
- 动画独立导出 FBX 时写入静止骨架，避免将当前动作姿势误写为骨架静止姿势。
- RE4 专用附加层控件和配置仅用于 RE4；动画取景使用当前姿态边界。

## 使用与验证

加载游戏 PAK 和配套路径 list，加载主角模型及对应动作列表。保留模型同目录的 JCNS 资源可使辅助骨约束参与预览和导出。FBX 导出继续使用本机 Blender。

- 211 个 Mesh 读取回归通过。
- JCNS 数学与游戏原生约束输出核对：24 个姿态、5616 个骨骼结果。
- 旧受击 0–4 号回归检查 383 帧，另核对 5 个不应转换的动作。
- 0、1 号 FBX 重新导入 Blender，各检查 17 个采样帧、两个视角；2–4 号各检查 5 个采样帧、两个视角，共检查 98 张渲染图，并核对 Blender 窗口截图。
- 0、1 号预览与两种动画导出 API 的蒙皮结果一致；独立 FBX 重新导入的最大表面误差小于 0.000018 米。

验证针对本机资源中的主角及上述动作；不代表全部角色、动作、物理布料、完整游戏状态机或 IK 均已验收。

Windows x64 发布包仅包含 ReExtractor-v1.4.10.exe。
