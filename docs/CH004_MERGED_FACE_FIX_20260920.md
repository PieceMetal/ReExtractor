# ch004 合并面部预览及 FBX 修复（2026-09-20）

## 根因与修复

身体缺失的面部骨骼在加载 MOT 时被补入；合并预览原先把这些辅助骨的全局姿势覆盖到头部真实骨骼。某些真实同名面部骨骼的绑定位置也不同，附加动画不能共享其绝对全局姿势。

- 标记 MOT 补入骨，避免作为其他分件的姿势来源。
- 附加轨道按各分件自己的绑定姿势求值。
- 导出中对辅助骨或绑定不同的同名骨保留独立别名轨道，不再强行复用身体骨。

## 已验证

- ch004 的 00、10、20 三分件；npc004_00_common.motlist.1036，mot_100。
- 真实 GlViewport CPU 蒙皮路径检查 62 个时刻，合并头部与独立头部最大偏差 0.0172 毫米。
- 完整 44.6 秒动画经生产导出脚本转换 FBX，重新导入 Blender。
- 0、2.52、22.3、44.59 秒比较真实蒙皮网格，固定静止骨架坐标基准；FBX 最大归一化误差 0.00009531，静止眼距 0.05825 米，约 0.0056 毫米。
- 18/18 既有合并回归通过；GUI 编译 0 警告 0 错误。
