# ReExtractor v0.1.1

本版本重点修复《街头霸王 6》模型能够读取、但预览中没有贴图的问题，并补充资源列表与本机游戏目录的自动匹配。

## 修复与改进

- 支持自动探测不同 RE Engine 游戏使用的 MDF2 文件版本，不再写死为 `.mdf2.50`。
- 支持《街头霸王 6》常见的 `_v00.mdf2.31` 材质命名。
- 补充 `.tex.241101895`、`.tex.143230113` 等贴图版本候选。
- 补充 `BaseAnisoShiftMap`、`BaseAlphaMap` 基础颜色槽识别。
- 选择已管理的资源列表后，可尝试从 Steam 库和常见游戏目录中自动找到对应游戏及 PAK。
- 保持原有《鬼武者：剑之道》`.mdf2.50` 贴图加载兼容。

## 实机验证

- 《街头霸王 6》目标角色模型已从 0 个贴图槽恢复为 7 个有效贴图槽，头部、牙齿、眼睛、头发和眼影贴图均能读取。
- 《鬼武者：剑之道》测试模型的原有材质与贴图读取回归通过。
- Windows x64 自包含版本构建通过，用户无需单独安装 .NET 运行时。

## 已知限制

- RE Engine 的皮肤、眼睛、头发和透明效果包含游戏专用着色器逻辑，当前预览与 FBX 材质主要还原基础颜色贴图，无法与游戏内最终画面完全一致。
- 新游戏仍可能使用新的 MDF、TEX 或 Mesh 版本，需要继续补充格式版本与材质规则。
