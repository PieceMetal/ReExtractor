# ReExtractor v1.3.3

本版本统一了发布物、程序标题和可执行文件的版本标识，方便同时保留多个版本进行对比和回退。

## 更新

- Windows x64 ZIP 与解压目录使用 `ReExtractor-v1.3.3-win-x64` 命名。
- 可执行文件使用 `ReExtractor-v1.3.3.exe` 命名。
- 主窗口标题和顶部产品标识显示当前完整版本号。
- 在线更新会下载并启动带版本号的新 EXE，旧版本不被覆盖，可手动回退。

## 使用提示

- 请完整解压 ZIP，保留 `ReExtractor-v1.3.3.exe` 和 `libGDeflate.dll` 在同一目录。
- 与旧版并存时，按文件名中的版本号选择要运行的版本。
