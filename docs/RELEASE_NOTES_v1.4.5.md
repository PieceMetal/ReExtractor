# ReExtractor v1.4.5

发布日期：2026-09-30。

## 更新

- RE4 玩家上半身配对预览改为读取当前 PAK 中的玩家层配置、启用的状态机动作、动作库与骨骼遮罩引用，解决其他动作列表的附加层下拉框始终只有“不叠加”的覆盖缺失。
- 选择有支持配对的主动作时，自动启用对应附加层；支持0%、50%、100%强度，并保留“不叠加”对照。不会按相邻编号或名称相似猜测配对。
- 修正静态站姿参考、附加层与上半身覆盖层的顺序，以及父状态继承的遮罩。
- 完整角色按骨架层级选择姿态驱动，避免头部骨架被错误用于身体，修复头胸塌陷和分件不同步。
- 动作列表显示源名称与编号，移除用途分类后缀。原始附加轨道保留在高级检查入口；修复首次加载、筛选及切换失败后的选择恢复。
- 组合仅用于预览，动画导出保留原始动作，并附带资源使用说明。

## 验证范围

- 对47份配置引用列表进行检查，30份包含当前可读取的配对，共214组；0%、50%、100%强度的全帧混合数据检查通过。
- wp4100h、wp4200h、general2 三份列表共298条主动作通过实际加载入口、默认配对及完整模型采样检查。
- wp4100h 和 general2 共32组通过完整里昂身体、头、发三分件逐帧蒙皮与共享骨骼同步检查；分件加载顺序检查通过。
- 代表动作离屏画面已查看，界面筛选、原始轨道、导出索引和失败恢复回归通过。上述数值检查不等于214组逐组视觉验收。

## 已知范围

本次配对支持限定于 RE4 共用玩家上半身配置，不代表所有 RE 引擎游戏或角色的完整分层模拟。当前底层使用静态站姿；跨列表基础动作继承、外部动作引用、移动层、手型覆写、动态权重与 IK 尚未完整还原。未列出配对不代表游戏没有叠加动作。

配置解析使用 REE-Lib 的 RSZ 元数据缓存；没有缓存时需要联网下载。干净机器离线运行未验收。没有新增对组合预览的烘焙导出，也未进行 UE 导入验收。

## 下载

`ReExtractor-v1.4.5-win-x64.zip` 内仅含 `ReExtractor-v1.4.5.exe`，无需安装 .NET；FBX 导出仍需 Blender。不包含游戏资源、本机预设、配置或路径列表。支持通过旧版“检查更新”安装。
