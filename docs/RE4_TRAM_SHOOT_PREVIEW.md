# RE4 矿车射击固定方向预览

反馈中的 `cha0_tram_0130_shoot` 是附加轨道。游戏的矿车状态机调用
`RailCar_Tree_Shoot`，按 YawBlend 混合三个持枪姿势后，通过 AddBlend 加入射击轨道。

本次修复提供该树的三个固定方向输入。加载角色身体模型与
`cha0_tram.motlist.663` 后，选择 101 正中、111 左侧或 121 右侧持枪循环，
会自动叠加 130；选择“不叠加”可查看相同时间内的持枪姿势。
130 单独播放放在高级“原始轨道”检查中。

组合引用、动作类型和遮罩从加载的矿车动作库、状态机、动作树、UVAR 与玩家 JMAP
读取。不能通过名字相似或动作编号相近扩展配对；不支持的树结构、混合模式或缺失资源
会产生诊断并隐藏配对。

固定方向预览先应用持枪姿势，再应用局部附加增量。它不经过通用玩家上半身的
站姿参考与覆盖层流水线。检查窗口采用射击轨道时长，开启、关闭及 0% 的时间一致；
此窗口仅用于动作检查，不代替游戏 FSM 的计时与状态切换。

“当前动画”导出当前组合；全部和批量导出原始轨道。导出组合结果作为普通动画播放，
不应再次设置为附加动画。

本次不求值实时 YawBlend、方向中间值、完整矿车状态切换、移动层或 IK。
不能将这三个方向的通过当成全部 shoot 动画或完整游戏效果已通过。

## 验证

`tools/Re4TramPreviewTests` 接收现有预览会话 JSON 和独立结果目录：

```text
dotnet run --project tools/Re4TramPreviewTests -c Release -- <session.json> <results>
```

会话包含本地 ListPath、GameDirectory、MeshPaths、MotionListPath，以及
BaseId=101、AdditiveId=130。脚本读取实际游戏资源，验证三方向配对、普通／原始轨道
分类、叠加与关闭／0% 的时钟和姿态、逐帧原生蒙皮、当前组合 GLB 和全部原轨道 GLB，
并检查离线快照仍隐藏未确认的160配对。加载实际HOLD/SHOOT配置时，普通枪械另由
专用解析器提供三条射击变体；详见 `RE4_PLAYER_SHOOT_PREVIEW.md`。
