# ReExtractor v1.4.18

修复《怪物猎人：崛起 / 曙光》玩家整套装备导入 Unity 后动画部件错位的导出路径。

## 修复内容

- 模型、当前动画、全部及批量动画从源资源准备同一完整玩家骨架，不再依赖是否预览过动画或装备加载顺序。
- 保留各部件原有蒙皮绑定与可见分组；动画加载不再向已准备的导出骨架追加临时辅助骨。
- 缺少完整玩家骨架资源时明确报错，不生成无法配套的结果。

## 使用方式

更新后重新加载配套 PAK/list，将整套模型和动画都重新导出，不能混用旧模型与新动画。用于 Unity 时两者均选择 Unity Y-up；验收使用 Generic、保留层级、关闭骨骼优化、Custom 8 权重以及运行时 Unlimited。

## 验证范围

- 男女 pl004 整套装备：未预览直接导出、冷/热导出一致性、装配顺序、隐藏分组、单部件及当前预览导出回归。
- 每个性别的双刀列表 192 个动画检查模型与动画骨架一致性。
- Unity 2021.3.45f2c1：男女各三个动作、30 个姿态，检查独立模型播放纯骨架动画 FBX，并查看头部、护手和背甲的多角度实际播放渲染。
- 代表样本通过不等于全部装备、全部动作、NPC、Humanoid 重定向或游戏 IK 已验证；纯色验收不覆盖贴图效果。
