# ReExtractor v1.4.1

修复《鬼武者：剑之道》过场面部动画播放及导出时的脸部塌缩、眼球和牙齿错位。

## 原因与修复

这类表情动画记录的是相对于骨骼绑定姿势的变化量。旧逻辑将几毫米的表情位移当作骨骼绝对位置，覆盖了原本的面部位置，导致五官被拉向错误的位置。

现在将面部位移与旋转叠加到目标骨骼自己的绑定姿势，统一覆盖预览、预览导出及动画导出。识别限定在本游戏的过场面部轨道，不改变普通身体动作和其它游戏的处理方式。

## 验证范围

- 本地主角头部及 3 个面部动画列表，共 22 个动作通过轨道与绑定姿势检查。
- 191 个身体动作保持原有绝对轨道语义；18 项模型合并回归通过。
- 3 个 FBX 各检查 5 个时刻、216 根面部骨骼，并核对预览与不同导出入口。
- 修复前后的头部渲染对比及张嘴中间帧检查通过。

尚未获得反馈者的原始模型与动画，未在其目标软件中验收。本次修复骨骼表情错位，不包含完整的形态键表情支持。
