# ReExtractor v1.4.9

修复 RE4 可选武器动作库读取失败时，其他正常武器的普通射击叠加配置也一起失效的问题。该故障会让原本需要基础持枪姿态的 500/501/502 射击增量轨道被当成普通动作，单独播放时接近 T 姿态。

现在分别隔离武器库和动作列表的异常；每个库的引用全部验证成功后才登记其资源上下文。失败资源会在日志中显示具体路径，公共玩家层、动作树和骨骼遮罩校验继续保留。

## 使用方法

对于已支持的普通枪械射击，主动作选择 160 持枪循环、165 左转或 167 右转，再从“配对附加层”选择 500/501/502 射击变体。导出组合效果请使用“当前动画”，导入后按普通动画播放。“全部动画”及批量导出仍保留原始轨道。

## 验证范围

- 五类故障回归通过：损坏库、缺失引用、混合有效/无效引用、损坏列表、库上下文原子登记。正常资源的 198 个普通射击组合保留，损坏列表只影响自身。
- `cha0_wp4000h_ex.motlist.663` 和 `cha0_wp4100h.motlist.663` 在正常资源及损坏库注入下，35 个已确认组合通过 GUI 选择、蒙皮与 GLB 导出读回；7 条原始 shoot 轨道通过加载和蒙皮检查。
- 本地打包程序中核对了两列表的 160 + 500 代表姿态。

反馈原环境有 18 个 PAK，本机验证环境有 9 个。此次修复针对已复现的程序缺陷，尚未确认反馈者实际安装中触发异常的具体资源；请更新后重新加载配套 PAK 和路径 list 复测。这不代表所有特殊 shoot、完整游戏状态机、IK 或 UE 已验收，也不新增对缺失 DLC 资源的支持。

本版保留 v1.4.8 的 RSZ 自动下载修复。
