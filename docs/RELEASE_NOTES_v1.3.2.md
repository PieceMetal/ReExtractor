# ReExtractor v1.3.2

本版本集中提升《怪物猎人：荒野》与《怪物猎人物语 3》的贴图、角色材质和组装预览兼容性。

## 新增与改进

- 集成 GDeflate TEX 解压，支持新版本 RE Engine 的压缩贴图。
- 《怪物猎人物语 3》角色预览支持 ALBR 身体/装备贴图、BCLO 毛发贴图、角色毛发和眉毛色、瞳孔 `COLR` 颜色层及默认瞳色。
- 自动过滤 MHS3 眼部折射镜片和 toon 轮廓壳，避免灰色遮罩盖住眼球或脸部。
- 角色合并预览会复用同一基础贴图的解码结果，降低大角色加载时的重复工作。
- 模型或预设加载贴图期间锁定会改变资源状态的界面操作，避免贴图请求串到其他模型。
- 便携包新增 `libGDeflate.dll`，并且在线更新会同时替换该原生库。

## 修复

- 修复《怪物猎人：荒野》Steam 游戏目录自动匹配。
- 修复加载预设后“加载贴图”按钮持续不可用的问题。
- 修复说明窗口不能通过 Esc 关闭的问题。

## 使用提示

- 请完整解压 Windows x64 ZIP，保留 `ReExtractor.Gui.exe` 与 `libGDeflate.dll` 在同一目录。
- 随包提供 MHS3 的“身体、头部、短发”角色组装预设，可在 `output/presets/MHS3_STM_Release/model-assemblies/` 中加载。
