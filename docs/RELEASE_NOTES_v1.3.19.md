# v1.3.19

- 新增 LOD0–LOD7 选择，默认 LOD0（最高精度），修复此前预览与模型导出固定读取 LOD1 的问题。
- 预览模型导出和批量模型导出使用所选档位；模型缺少该档时使用现有最后一级。
- 切换 LOD 会重新加载当前模型组合，重置动画和可见组，需要重新点击“加载贴图”。预览模型导出期间禁止切换档位。

验证：静御前身体在 LOD1 的默认可见三角面为 9,220，切换 LOD0 后为 19,022；最高精度站立四分件实际生成合并 FBX 和 66 张 PNG，其中包含 16 张 NRRO。两张三维特效纹理仍不支持，日志会记录失败原因。

法线及辅助贴图保存在导出目录的 `textures` 子目录中，不自动连接 FBX 材质；`.fbm` 目录主要保存基础色贴图。
