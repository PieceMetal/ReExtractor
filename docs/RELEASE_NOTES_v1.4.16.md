# ReExtractor v1.4.16

让复用动作的列表更容易辨认：保留各自的资源入口，正常列出和加载动作，并在界面中同时标明当前列表与动作来源。

## 更新内容

- 继承动作的提示同时显示当前列表名称、可读取动作数量，以及所选动作实际来自的基础列表。悬停可查看两个完整路径。
- 动作下拉框继续使用资源原有名称，预览与导出仍通过当前选中的列表读取；不同列表的入口保持独立。

## 验证与边界

- 本机《鬼武者：剑之道》em112 攻击列表在独立入口列出 67 个动作；67 个动作均能用对应 ch102 模型读出有效时长与轨道。
- 后台界面验证了来源提示、67 个下拉项，以及首、中、末动作切换后的模型姿态。未进行反馈者环境或实际窗口视觉验收。
- 反馈日志中另外两次“没有可读取的动作”未记录对应列表路径，原因尚未确认；本版不宣称解决该问题。
