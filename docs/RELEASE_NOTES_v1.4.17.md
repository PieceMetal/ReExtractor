# ReExtractor v1.4.17

修复场景预览中模型或动画移动到画面外、被前后裁剪面截断的问题。

## 更新内容

- 选择动作时，根据整段动作的可见模型范围取景；播放或拖动时间轴遇到采样点之间的快速位移时，继续扩展取景范围。
- 修正透视镜头与模型边缘距离不足的问题，并根据模型相对镜头的实际深度设置前后裁剪面。
- 窗口尺寸和视图方向改变时重新适配取景；地面网格覆盖当前动画的移动范围。手动缩放、平移和局部取景仍由用户控制。

## 验证与边界

- 使用《鬼武者：剑之道》em112 对应模型和 59 号动作，检查完整 5.33 秒动画的 61 个时间点；可见顶点均位于视口及前后裁剪范围内。
- 用采样点之间快速移动的测试动作检查自动扩展取景，并检查窄窗口、正交视图和手动缩放。
- 后台界面检查 em112 的 67 个动作入口及首、中、末动作切换。尚未在反馈者的电脑上进行实际窗口视觉验收。
