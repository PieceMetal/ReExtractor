# ReExtractor v1.4.19

- 新增“导出参考姿势 FBX”，加载角色模型后无需加载动画列表即可导出当前绑定参考姿势。
- 导出当前动画、动画列表或批量动画时，自动在各自输出目录附带同一骨架的参考姿势 FBX，支持现有 UE 和 Unity 轴向。
- 参考姿势使用模型现有的绑定姿势，不会自动转换为标准 T Pose 或 A Pose。部分动画加载后可能补充辅助骨骼，需使用该次动画导出的配套参考姿势，或在加载动画后重新独立导出。

下载 `ReExtractor-v1.4.19-win-x64.zip`，解压并运行其中的 `ReExtractor-v1.4.19.exe`。FBX 导出需要已安装 Blender 并在程序中配置其路径。
