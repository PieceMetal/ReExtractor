# ReExtractor v1.3.14

本次更新修复《街头霸王 6》的角色材质预览与导出贴图。

- 读取服装 CMD 基础配色及默认颜色 001 的启用覆盖项，按身体、头部、头发区分同名材质；修复皮肤发黑和毛发发白。
- 缩放染色蒙版和毛发覆盖贴图时保留独立通道，修复衣服染色区域丢失和异常亮色斑点。
- 保留胡子及布料散线使用的纯色底图和固定染色蒙版，修复肯的白胡子、隆破布边缘的灰白散线。
- 合并模型时区分同名贴图的不同配色结果，避免眉毛颜色覆盖头发。
- 省略通用预览和导出尚不支持的 SF6 泪膜覆盖层，消除眼下不透明白边；未实现游戏原有的透明湿润着色效果。

## 验证范围

- esf001、esf009、esf010 头部的皮肤、毛发、眼球保留及配色检查通过。
- 肯 001 完整角色的胡子颜色、覆盖范围及合并材质检查通过。
- 隆 001 身体原有 5,006 个无材质可见面已加载深红色散线材质，修复前后使用相同 Blender 相机与光照对比。
- 18 项模型合并回归测试通过；用户在修复版工具中试用后确认可以发布。
- Blender 对比验证的是导出外观，不等于游戏完整着色器还原；未修改游戏资源文件。
