# ReExtractor v1.3.0

本版本新增 RE Engine 场景与预制体的静态内容预览、导出，并扩大《怪物猎人：荒野》等新格式资源的兼容范围。

## 新增

- 识别并解析 `.scn.*` 场景和 `.pfb.*` 预制体文件。
- 重建 GameObject 父子层级，读取 `via.Transform` 的位置、旋转和缩放。
- 自动加载场景内 `via.render.Mesh` 静态模型并烘焙世界变换。
- 场景预览可直接合并导出为 FBX。
- 状态栏报告对象数、模型引用数、成功加载数、PFB 引用数和缺失资源数。
- 根据当前游戏资源列表识别 MHRise、MHWilds、DD2、SF6、RE4、RE8，并按场景版本提供回退识别。

## 修复

- 《怪物猎人：崛起》解包资源的 `@` 路径、角色资源根目录和 `.tex.28.STM` 贴图解析。
- 《怪物猎人：荒野》`.mdf2.45` 材质与贴图查找。
- 无蒙皮辅助 Mesh 的权重缓冲越界，避免场景加载中单个刚性物件导致整体失败。

## 当前边界

- 支持可离线还原的静态 Mesh、层级和变换；Alembic、碰撞、导航、粒子、灯光、脚本及运行时程序化地形暂不转成可编辑模型。
- 带骨骼角色不会作为静态场景物件错误烘焙；角色模型和动画仍使用独立的 Mesh/MotionList 流程。
- 首次解析某款游戏的 SCN/PFB 时，底层库可能需要联网获取并缓存该游戏的 RSZ 类型数据。
