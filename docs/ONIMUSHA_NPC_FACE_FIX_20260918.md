# 鬼武者 NPC / 敌人面部骨骼修复验收（2026-09-18）

本轮修复面部骨骼偏移解释错误，不包含完整形态键表情系统，也没有发布软件包。

## 修改

- OniWS 面部动作不再只靠 `_face` 名称判断；识别实际 `/face/` 资源目录，覆盖对话、演出和常规面部动作。同名身体动作保持绝对轨道。
- 补齐 NPC 的 LOD0/LOD1、眼球、下颌、牙齿、面部根和颈部修正骨。
- 补齐多眼角色和 em510、em512/em513、em507 不同命名体系的面部骨骼。普通 NPC 的 `R_Eye/L_Eye` 绝对辅助轨道保留原含义。
- 敌人面部目录中的 `plw_` 玩家反应动作保持绝对轨道，不拿它们冒充敌人的面部动作做验收。
- 预览与两种动画导出入口共用判定；旧导出入口遇到非零骨骼哈希无法匹配时跳过该轨道，不再错误回退到其他骨骼序号。

## 实测范围

资源来源为本机 `E:/Steam/steamapps/common/OnimushaWotS`。盘点了 930 个面部 motlist；这不是 930 个列表全部通过视觉验收的声明。

对 ch0 下的 20 个独立头部模型查找动作。敌人模型依据游戏角色预制体的真实 mesh 引用匹配 em 编号，而非猜测与 ch 相同的 npc 编号。

16 个角色、31 个代表列表、353 段动画通过轨道有限值、零偏移保留绑定姿势、形态控制不当作骨骼、遗漏零偏移轨道检查：

- ch001 6；ch002 38；ch003 36；ch004 49。
- ch010 8；ch012 1；ch020 16；ch021 11。
- ch023 31；ch024 1；ch033 14；ch034 21。
- ch035 48；ch038 28；ch039 4；ch040 41。

每个选定列表导出一个代表动作，在开始、中间和结束生成渲染；人工检查各角色代表图及重点异常动作。渲染是通过生产动画读取器导出的 GLB 在 Blender 中进行的，使用白模和检查相机，不是游戏原画面，也不是每段动画逐帧人工检查。

ch011/em504、ch037/em501、ch051/em301、ch052/em300 未找到可直接配对的自身面部动作；目录里的玩家反应动作已排除。这四个模型只有静态检查，不计入动画通过数。

其他回归：

- 22 段主角面部动作及 191 段主角身体动作。
- 51 段 NPC/敌人对话身体动作、140 段玩家反应动作保持绝对轨道。
- 7 类真实面部样本的关键骨骼正向检查，以及 npc021 眼部辅助轨道反向检查。
- 13 个代表样本，每个 5 个时间点，比较预览、主导出、旧导出和 FBX 回读的共同骨骼相对距离。最大误差为眼间距的 0.00042403，低于阈值 0.002。此检查不等于完整材质、形态键或游戏状态机还原。
- 合并回归 18/18；GUI 编译 0 警告、0 错误。
