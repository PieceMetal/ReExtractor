# ReExtractor v1.4.7

## RE4 射击预览

部分 shoot 轨道只包含射击增量，直接作为完整姿态播放会接近 T 姿态。本版按加载的游戏动作库、状态机和动作树读取已确认的基础姿态与射击关系。

- 矿车：选择 101 正中、111 左侧或 121 右侧持枪基础动作，自动叠加 130；可切换“不叠加”对照。
- 普通枪械：22 个武器动作库提供 160 持枪、165 左转、167 右转基础输入与 500/501/502 射击变体，共 198 个固定输入组合。11 个动作库通过显式继承链补齐 33 条基础输入，并显示继承来源。
- 静态持枪姿态保留源动作声明的检查时长。wp4410H 的三条射击轨道没有骨骼增量，界面明确提示“零增量”，开关叠加不会凭空产生后坐力。
- “当前动画”导出所选组合，导入后作为普通动画使用。全部／批量导出保留 RE4 列表原始内嵌轨道，不自动生成射击组合或扩展继承内容。

固定输入预览不求值游戏中的动态转向、速度、随机变体、其他活动层或 IK。510 aftershoot、1130 等特殊 shoot 尚未据此确认，不能将本版范围视为全部 shoot 或完整游戏动作效果。

## 鬼武者：剑之道 动作读取

修复 `em101_00_01_damage.motlist.1036` 提示“没有可读取的内嵌动作”的问题。该列表通过 `BaseMotListPath` 引用基础列表；motbank 登记动作列表，并不直接存放 MOT 动作数据。

预览、当前动画、全部动画及批量导出可以读取已加载资源中的基础列表继承动作。按动作编号与分支匹配，保留本地覆盖，缺失、重复、循环或损坏的引用会明确报错；请同时加载配套 PAK 或资源目录。

## 验证范围

- RE4：415 个已确认组合的界面选择、数值、角色蒙皮及当前组合 GLB 读回检查，包含 198 个普通射击组合、214 个已有上半身组合和 3 个矿车方向组合；73 条原始 shoot 轨道读取检查。9 个组合对应已确认的零增量源轨道。
- 鬼武者：148 个 damage 动作与基础源关键帧一致，148 个 GLB 导出读回；16 个同角色战斗列表共 1059 个动作读取。补充无窗口界面的动作选择、切换与蒙皮检查，以及代表 FBX 导出读回。
- 自动检查不代表所有动作已经逐个人工看过，也不代替游戏或 UE 运行验收。

本版尚未包含独立 RE4 资源管理界面。详细解析与验证方法见 [普通枪械说明](RE4_PLAYER_SHOOT_PREVIEW.md)、[矿车说明](RE4_TRAM_SHOOT_PREVIEW.md)和 [外部引用测试说明](../tools/ExternalMotionTests/README.md)。
