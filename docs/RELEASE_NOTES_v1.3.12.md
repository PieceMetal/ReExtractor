# ReExtractor v1.3.12

## 修复

- 修复 v1.3.11 引入的多分件模型导出回归：骨骼数量不同但绑定兼容的《怪物猎人：荒野》《街头霸王 6》等角色分件现在可以合并为一个模型导出。
- 导出使用骨架并集检查，允许额外骨和缺失父链的合法子集，保持原有顶点权重映射。共用骨的绑定变换、父级冲突与合并后的层级循环仍会阻止导出。
- 保留 NPC 预览共享姿态的严格骨架检查。
- 恢复无骨架静态模型的合并；静态与蒙皮模型混合时，静态顶点绑定到独立固定根骨。

## 验证

- 18 项合成回归测试全部通过；相同测试在 v1.3.11 的合并实现中有 8 项失败。
- 使用发布依赖版本的干净源码重复执行测试并构建单 EXE。
- 程序化检查：荒野 `ch03_001_000` 的 6 个分件，以及街霸 `esf001_000/001/002`、`esf002_002`、`esf003_000/001/002` 共 7 组资源样本均通过合并及 GLB 导出。这些分组按资源路径选取，包含内部骨骼和道具，不代表完整角色外观验收。
- 核对 3,234,638 个权重目标/数值，合并前后保持一致；静止蒙皮顶点最大偏差为 `7.451e-9`。
- 8 组模型完成 FBX 转换并由 Blender 回读：各为一个模型、一副骨架，蒙皮组映射有效，FBX 单位为厘米。
- 街霸 `esf002_000` 中 `_10` 分件的 `C_Head` 存在实际绑定差异，仍按预期拒绝合并。
- GUI 检查：在 v1.3.12 中合并加载春丽 `esf004/001` 的 `00` 头脸、`01` 身体服装、`02` 头发三个分件，确认完整静态外观显示。
- 用户手动检查：上述春丽完整组合由用户执行导出，反馈“感觉还行”。此反馈不扩展为全部角色或动画验收。

回归测试命令：`dotnet run --project tools/MergeRegressionTests -c Release`。

本次仅验证上述本地样本，未验证所有角色、服装及动作组合。
