# ReExtractor v1.4.13

本版修复《鬼泣 5》尼禄蓝玫瑰蓄力射击的组合动画预览与导出。

## 修复

- `natives/x64/animation/player/pl0000/motlist/pl0000_br.motlist.85` 中，680 空中蓄力射击只有腰腿等局部轨道。游戏实际调用的 700 动作树还组合了上半身射击轨道；旧版跳过动作树，单独播放或导出 680 时会缺少肩臂、手部等动作。
- 现在按原动作树节点、连接和配套动作库解析已支持的组合，670 / 680 自动补全对应的地面 / 空中蓄力射击；690 / 700 组合动作也可直接选择。缺少配套动作库会明确报错，不猜测来源。
- 预览、当前动画导出和全部 / 批量导出对这些已识别动作使用相同组合。其他动作不自动套用此处理，原模型的逆绑定矩阵保持不变。

## 使用

更新后重新加载角色及上述动作列表，选择带“正前方组合”标记的 680 或 700。之前导出的局部动画需要重新导出；导出的组合按普通动画播放，不要再次设置为叠加动画。

670 / 680 的原始二进制资源仍可通过资源提取取得。

## 验证范围

- 使用现有 DMC5 PAK 中的尼禄身体、头部、头发和人类手臂四个分件，在后台加载，不操作桌面窗口。
- 680 / 700、670 / 690 的组合与对应原始上下身轨道采样比较通过；非目标动作、非目标路径、缺少配套动作库的检查通过。全部导出包含 29 条 MOT 和 2 个已支持的组合动作。
- 使用应用自身的姿态计算器检查第 0、20、40、65、83 帧，另生成多个时刻的修复前后对比图与动图。
- 代表空中组合的 GLB 与动画 FBX 经 Blender 分别导入，在第 0、7、20、40、65、83 帧对比髋、腰、胸、头、双臂、双手、双脚的骨骼位置；最大 FBX 回读误差约 `1.3e-6 m`。

当前支持**正前方固定瞄准输入**。未模拟游戏实时方向混合、武器控制和状态切换，尚未进行 Unity / UE 编辑器实际导入或游戏运行时验收。这不代表全部尼禄动作或其他 DMC5 角色的组合均已支持。

Windows x64 发布包：`ReExtractor-v1.4.13-win-x64.zip`，仅包含 `ReExtractor-v1.4.13.exe`。
