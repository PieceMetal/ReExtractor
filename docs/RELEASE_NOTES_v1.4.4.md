# ReExtractor v1.4.4

## 修复

- 游戏扫描跳过零字节 PAK 占位文件，避免 RE2 安装目录中的空补丁文件中断加载；路径 list 没有匹配到资源时给出提示。RE2 RT 资源应使用对应的 `RE2_RT_STM_Release.list`。
- RE RT / MOT 492 动画播放与动画导出增加骨架兼容性检查。面部动作把 `spine_2` 当作根节点、身体模型却把它放在 `spine_1` 下时，明确提示层级不兼容，避免上半身被拉长。仅共享通用根骨骼名的独立武器动作也不再直接套用到身体模型。
- 补齐 RE RT 骨骼缩放轨道，贯通解析、两种预览视口及两条 GLB 动画导出路径，FBX 转换保留缩放。此前部分肌肉等辅助骨骼的非单位缩放被忽略。
- 动作切换失败时恢复上一条成功选择，过期的异步动作请求不再覆盖新选择。
- 保留动画原始位置与根运动。场景动画自带位置偏移、行走动画向前移动属于源数据行为。

## 验证

- RE2 RT 安装目录扫描：15 个非空 PAK、42,237 个已解析资源。
- pl0000 身体模型的 158 个玩家动作列表中，共检查 1,582 条内嵌动作。1,536 条通过每条 9 个时间点、合计 13,824 个时间点的蒙皮抽样；未发现非有限坐标、关键帧时间倒序或身体包围盒大幅拉伸。
- 其余 46 条分别为与该身体分件不匹配的 39 条面部动作，以及 7 条 `dummy` 占位动作。另有 37 个列表仅含外部动画引用，未计为已播放验证。
- 基础动作组的 62 条动作另外完成每条 17 点检查；同一模型连续切换“待机 → 拒绝面部动作 → 行走 → 待机”，姿态没有残留，被拒绝的动画没有修改模型骨架。
- 待机、行走 GLB 导出回读通过。受伤动作的实际非单位肌肉缩放在两个视口和两条 GLB 导出路径中验证；后台 Blender 导出 FBX 并回读后，缩放分量误差小于 0.000001。
- 最新修复代码的待机 #160 已完成 GUI 播放目测；骨架不兼容提示也已实际验证。仓库附带 `tools/Re2AnimationRegressionTests`，需自行提供本地游戏资源与路径列表。

## 已知范围

分离面部动画的配套身体姿态与骨架空间转换尚未实现；本次增加误配防护，不代表已支持其正确合成播放。上述抽样针对 RE2 RT 的 pl0000 身体模型，不保证每一帧与游戏一致，也不代表所有角色、游戏及外部动画引用都已验证。未进行 UE 导入验收。

## 下载

`ReExtractor-v1.4.4-win-x64.zip` 内仅含一个 `ReExtractor-v1.4.4.exe`，无需安装 .NET；FBX 导出仍需 Blender。不包含游戏资源、本机预设、配置或路径列表。
