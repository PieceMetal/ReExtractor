## GPU 模型不显示——GL 上下文线程 bug（14:52）
- 现象：网格线/骨骼线正常，模型三角形全空白，Vao==0。
- 根因：ANGLE 的 GL 上下文绑定在渲染线程，`SetMesh` 从 UI 线程调用，此时 `_gl != null` 但在错误线程调用 `UploadGeometry` → VAO/VBO handle 全返回 0（静默失败）。
- 修复：`CreateModel` 中删除 `if (_gl != null) { upload() }` 分支，**无论 _gl 是否已初始化都走 `_pendingUpload`**。同时 `OnOpenGlRender` 开头处理 pending 上传（渲染线程，上下文正确）。这样所有 GL 对象创建都在渲染线程完成。
- **钉死**：Avalonia ANGLE 模式下 GL API **只能在渲染线程（OnOpenGlInit/OnOpenGlRender）内调用**，UI 线程调用 GL 静默返回 0/失败。
